### <a name="_qmphm5d6rvi3"></a>**Решение**
В отдельных файлах приведены диаграммы контекста и контейнеров в модели C4.

Для передачи информации о депозитных ставках из АБС в систему внутреннего кол центра будет использоваться очередь сообщений Kafka (требования 1, 2, 5, 6). 

Взаимодействие между АБС и внутренним кол центром производятся с использованием TLS шифрования (4). Шифрование беспечивается настройкой site-to-site vpn на пограничных межсетевых экранах. Для этого предлагаемые технические решения по развитию системы должны быть согласованы с сотрудниками, отвечающими за ИБ и, при необходимости, должен быть иниицирован проект по перенастройке системы ИБ банка.

Для передачи информации о депозитных ставках из АБС в систему внешнего кол центра будут файлы, которые система внешнего кол центра будет забирать по протоколу FTPS (4, 7) с сервера, развернутого в ЦОД АБС.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Принципиальных альтернатив не рассматривалось.

**Недостатки, ограничения, риски**

Архаичная архитектура взаимодействия с внешним кол центром не позволяет получить подтвердение приема и загрузки актуальных ставок депозита в CRM систему кол центра.

Необходимость привлечения ИБ подразделения усложняет, удорожает и замедляет реализацию проекта.
